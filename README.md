# supabase-send-email-hook
Supabase Auth Send Email hook (Edge Function) that sends auth emails through the MailChannels Email API.

## Support
This project is supported by the MailChannels team on a best-effort basis. The best way to get support is to file an issue on GitHub: https://github.com/mailchannels/supabase-send-email-hook/issues

If you are a MailChannels customer and have a problem with the operation of the MailChannels service, you can get support at https://support.mailchannels.com/
